# Responsive Analytics Dashboard

A modern, responsive analytics dashboard built using HTML5, CSS3, and JavaScript. This project demonstrates a token-based design system and mobile-first responsive CSS architecture.

## Features

- **Design Tokens:** CSS custom properties for colors, typography, spacing, and border radii.
- **Responsive Layout:** Dashboard layout adapted for mobile, tablet, laptop, and desktop screens.
- **Light and Dark Themes:** Theme toggle with saved theme preference.
- **Analytics Cards:** Summary cards for key dashboard metrics.
- **Revenue Chart:** Interactive chart period selector for week, month, and year.
- **Project Progress:** Visual progress indicators for projects.
- **Recent Activity:** Activity section for dashboard updates.
- **Mobile Navigation:** Responsive sidebar navigation.
- **Interactive Notifications:** Toast messages for selected dashboard actions.
- **Modern UI:** Glassmorphism effects, shadows, rounded corners, and hover transitions.

## Technologies Used

- HTML5
- CSS3
- CSS Custom Properties
- Responsive Media Queries
- JavaScript (Vanilla)

## Responsive Breakpoints

| Viewport Width | Device Category |
|---|---|
| 320px–767px | Mobile |
| 768px–1023px | Tablet |
| 1024px–1439px | Laptop |
| 1440px and above | Desktop |

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or run it using the Live Server extension.
4. Use Chrome DevTools Device Toolbar to test different viewport widths.
